# Идеи по дизайну и фишкам

## Интерфейс и UX

- **Сообщения об ошибках по типу** — использовать `errorType` из API (`network` / `server` / `timeout`): показывать «Нет подключения к интернету», «Превышено время ожидания», «Ошибка сервера» и кнопку «Повторить» там, где данные критичны (логин, списки расходов/переводов).
- **Pull-to-refresh везде** — на экранах со списками (расходы, пробег, переводы) уже есть или можно добавить единый компонент Pull-to-refresh для обновления без перезахода.
- **Скелетоны вместо спиннера** — на местах загрузки списков (карточки расходов, переводы) показывать скелетон-карточки вместо одного Loader2: так понятнее, что грузится.
- **Пустые состояния** — на «Нет расходов» / «Нет переводов» добавить короткий текст и одну кнопку действия (например, «Добавить расход» или «Сделать перевод»), чтобы не оставлять пустой экран.
- **Подтверждение выхода** — в профиле перед logout показывать AlertDialog «Выйти из аккаунта?», чтобы снизить случайные выходы.
- **Роль в сайдбаре/навбаре** — в нижней навигации или в шапке показывать иконку/букву роли (А / Б / В или иконки), чтобы пользователь видел, под кем зашёл.

## Фишки

- **Фильтр по периоду на бэкенде** — на экранах с датами (расходы, пробег, переводы) передавать в API `since`/`until` и грузить только выбранный период; при первом открытии — последние 30 дней. Меньше данных и быстрее открытие.
- **«Подгрузить ещё»** — для длинных списков вызывать `getExpenses`/`getTransfers`/`getMileage` с `offset` и `limit` (например, по 50), кнопка «Ещё» внизу списка или бесконечный скролл.
- **Офлайн-индикатор** — маленький баннер или иконка в шапке при `navigator.onLine === false` и показ сообщения «Данные могут быть неактуальны» при восстановлении сети.
- **Быстрый переключатель валют** — на карточках баланса тап по валюте открывает мини-историю (последние операции по этой валюте) или тултип с подсказкой.
- **Сводка по периоду** — на экране расходов админа/баланса: «За выбранный период: сумма расходов по валютам» (считается по уже загруженным данным или отдельным запросом).
- **Экспорт по выбранному периоду** — в экспорте Excel использовать текущий фильтр по датам (если есть), а не все данные.

## Визуал

- **Акценты по ролям** — лёгкий цветовой акцент для ролей (например, админ — синий, баланс — зелёный, водитель — нейтральный) в шапке или в карточке профиля.
- **Иконки категорий расходов** — у каждой категории из справочника своя иконка (lucide-react), в списке расходов — иконка слева от категории.
- **График пробега** — на экране пробега админа простой линейный график «км по дням» по выбранному водителю и периоду (например, recharts или аналоги).
- **Тёмная тема** — уже есть переключатель; проверить контраст карточек и границ (border) в тёмной теме на всех экранах.
