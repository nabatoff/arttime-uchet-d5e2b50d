

# Редизайн приложения + переключение тем

## Референс
Скрин показывает финтех-стиль: глубокий темный фон, карточки с мягкими скруглениями и тонкими границами, крупная типографика для сумм, минималистичная навигация с иконками и точками-индикаторами. Акцентный цвет -- красный (уже используется).

---

- Создать `ThemeContext` с переключением `light` / `dark`, сохранением в `localStorage`

- Темная тема остается текущей по умолчанию
- Кнопка переключения (иконка солнце/луна) в шапке `PageLayout` и на странице `Profile`

### 2. Обновление дизайн-системы (`index.css`)
- Светлая тема: `--background: 0 0% 97%`, `--card: 0 0% 100%`, `--foreground: 0 0% 10%`

- Добавить мягкие тени для карточек в светлой теме
- Обновить glass-эффекты для обеих тем

### 3. Редизайн страниц в стиле референса

**Dashboard (водитель и админ):**
- Приветствие в виде компактной строки с именем и датой (как "Hello Oleksandr" на скрине), вместо большого красного блока

**Навигация (BottomNav):**

**Карточки расходов/пробегов:**

**Login:**

## Технические детали

- Тема управляется через CSS-класс `dark` / `light` на `<html>` (уже настроен `darkMode: ["class"]` в tailwind.config)
- `ThemeContext` хранит значение в `localStorage` под ключом `app-theme`
- По умолчанию -- темная тема
- Все существующие компоненты продолжат работать, т.к. используют CSS-переменные
